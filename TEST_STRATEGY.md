# ArtPlus — TEST_STRATEGY

## 1. Principles

- A test only counts when it has been **executed** and its output is recorded.
- Tests are deterministic: no reliance on network, on the ArtPro+ installation,
  or on unpublished fixtures.
- Rendering/UI behaviour is tested at two levels:
  - **logic level** (pure maths, no window),
  - **integration level** (real `MainWindow`, real PDF, real PDFium).
- Preservation and error handling are first-class test targets, not afterthoughts.

## 2. Current test executables (milestone 21)

| Executable | Level | Covers |
|---|---|---|
| `artplus_pdf_smoke` | engine (headless) | open, page count, page size, metadata, render page 1 + last page, thumbnail, invalid input, source preservation (SHA-256) |
| `artplus_pageview_test` | viewport logic | fit page, aspect ratio, zoom in/out round trip, actual size, zoom clamping, view rotation, drag pan |
| `artplus_mainwindow_test` | GUI integration | startup state, open, page count, first page, fit zoom, next/previous/goToPage, actual size, zoom in/out, fit page/width, rotation, close |
| `artplus_import_test` | import model (M22) | snapshot page count, Media Box vs page size, box defaults, object kind classification, source hash, byte-identical Save As Copy, reopen copy, overwrite refusal |
| `artplus_edit_test` | editable geometry + round-trip (M22.2) | fixture (rect, cubic, text, image, form) import, cubic control points, translation, incremental/full save verification, multipage save, untouched page dimensions, reopen keeps the move, other objects unchanged, source untouched, overwrite refused |
| `artplus_command_test` | commands / undo-redo / properties (M23) | move/undo/redo, resize anchor, rotation + reporting, ten-move drift, clean/dirty transitions, multi-operation save + reopen, independent history |

`artplus_inspect <pdf> [page]` is a diagnostic CLI that prints object kinds,
bounds and matrices; it is used to produce before/after evidence.

## 4. Manual / visual checks (milestone 21)

1. `ArtPlus.exe` starts and shows the main window (no crash).
2. Open a PDF with the dialog → page renders, page list populated, metadata shown.
3. Drag & drop a `.pdf` onto the window → same result.
4. `ArtPlus.exe file.pdf` → opens that file.
5. Zoom in/out, fit page/width, 100 %, wheel over the page.
6. Drag to pan.
7. Rotate 90°.
8. Navigate with page list, spinner, previous/next.
9. The source file is not modified (compare hash before/after).

## 5. Fixture set (planned, milestone 22+)

Minimum corpus to add under `tests/fixtures/`:

- single-page PDF; multi-page PDF
- different page sizes (A4, Letter, custom)
- text, vector, image, transparency
- RGB, CMYK, spot colours
- embedded fonts and non-embedded fonts
- invalid/truncated file; password-protected file
- PDF/X and PDF/A samples
- documents with CropBox/TrimBox/BleedBox/ArtBox differences

Fixtures must be licence-clean; generated fixtures are preferred.

## 7. Regression policy

- Every fixed bug gains a test before the fix is merged.
- The full suite must be executed before declaring a milestone done.
- Failures must be reported with the exact command, input, and output.
