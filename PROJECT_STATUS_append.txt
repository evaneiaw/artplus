### Documento (Investigação Técnica)

Funcionalidades existentes: Crosshair toggle e Page Boxes visibility toggle funcionam
connectivamente. Não exibe metadados do documento (pages, size, title, author).
Apenas habilitado/desabilitado quando mudar documento.

`title()`, `author()`, `subject()`, `creator()`, `creationDate()`, `modificationDate`.

Limitações: Painel não consome estas APIs para populacão de dados. Apenas dois botões
funcionais conectados ao `m_view`. Nenhum dado de documento é extraído de `m_doc`
ou `m_snapshot` para exibição no painel.

Desenvolvimento necessário: Integrar `m_doc` e `m_snapshot` ao painel para exibir
page count, dimensions, metadata e output intent. Atualizar `updatePanels()` para
populacão de dados ao abrir documento.
